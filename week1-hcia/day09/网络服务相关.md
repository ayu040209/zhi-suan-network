# HCIA - 网络服务与应用

## 一、核心概念速记（面试口述用）

| 概念 | 一句话定义 | 面试口述话术 |
|------|-----------|-------------|
| FTP | 文件传输协议，基于TCP的C/S架构文件传输服务 | "面试官你好，FTP是文件传输协议，使用TCP端口21控制连接、端口20数据连接，支持ASCII和二进制两种传输模式。" |
| TFTP | 简单文件传输协议，基于UDP的轻量级文件传输 | "TFTP基于UDP端口69，无需认证，适合传输小文件如设备配置文件、系统镜像。" |
| Telnet | 远程登录协议，基于TCP端口23 | "Telnet提供远程命令行管理功能，基于TCP端口23，但明文传输不安全，生产环境建议使用SSH替代。" |
| DHCP | 动态主机配置协议，自动分配IP地址等网络参数 | "DHCP采用C/S架构，通过Discover-Offer-Request-Ack四次交互自动分配IP地址、子网掩码、网关、DNS等参数。" |
| HTTP | 超文本传输协议，应用层协议用于Web通信 | "HTTP是Web通信的基础协议，使用TCP端口80，采用请求-响应模式，是无状态协议。" |
| DNS | 域名系统，将域名解析为IP地址 | "DNS是分布式的域名解析系统，支持递归查询和迭代查询，使用UDP端口53。" |
| NTP | 网络时间协议，用于同步网络设备时钟 | "NTP用于在分布式设备间同步时钟，使用UDP端口123，通过分层架构实现高精度时间同步。" |

## 二、华为命令配置模板（直接复制粘贴）

### 场景1：配置设备作为FTP服务器

```bash
# 步骤1：开启FTP服务
[FTP_Server] ftp server enable

# 步骤2：创建FTP用户（AAA方式）
[FTP_Server] aaa
[FTP_Server-aaa] local-user admin1234 password irreversible-cipher Helloworld@6789
[FTP_Server-aaa] local-user admin1234 privilege level 15
[FTP_Server-aaa] local-user admin1234 service-type ftp
[FTP_Server-aaa] local-user admin1234 ftp-directory flash:

# 验证命令
[FTP_Server] display ftp-server
[FTP_Server] display local-user
```

### 场景2：配置DHCP接口地址池

```bash
# 步骤1：全局使能DHCP
[Router] dhcp enable

# 步骤2：进入接口配置DHCP接口地址池
[Router] interface GigabitEthernet 0/0/0
[Router-GigabitEthernet0/0/0] ip address 10.1.1.1 24
[Router-GigabitEthernet0/0/0] dhcp select interface
[Router-GigabitEthernet0/0/0] dhcp server dns-list 10.1.1.2
[Router-GigabitEthernet0/0/0] dhcp server excluded-ip-address 10.1.1.2 10.1.1.10
[Router-GigabitEthernet0/0/0] dhcp server lease day 3

# 验证命令
[Router] display ip pool interface GigabitEthernet0/0/0 used
```

### 场景3：配置DHCP全局地址池

```bash
# 步骤1：创建全局地址池
[Router] ip pool pool2
[Router-ip-pool-pool2] network 1.1.1.0 mask 24
[Router-ip-pool-pool2] gateway-list 1.1.1.1
[Router-ip-pool-pool2] dns-list 1.1.1.1
[Router-ip-pool-pool2] lease day 10

# 步骤2：接口关联全局地址池
[Router] interface GigabitEthernet 0/0/0
[Router-GigabitEthernet0/0/0] dhcp select global

# 验证命令
[Router] display ip pool name pool2 used
```

### 场景4：配置Telnet服务（AAA认证） [补充]

```bash
# 步骤1：开启Telnet
[Router] telnet server enable

# 步骤2：创建AAA用户
[Router] aaa
[Router-aaa] local-user huawei password irreversible-cipher Huawei@123
[Router-aaa] local-user huawei privilege level 15
[Router-aaa] local-user huawei service-type telnet

# 步骤3：配置VTY使用AAA认证
[Router] user-interface vty 0 4
[Router-ui-vty0-4] authentication-mode aaa
[Router-ui-vty0-4] protocol inbound telnet

# 验证命令
[Router] display telnet server status
```

## 三、思科-华为迁移对照表

| 思科命令 | 华为命令 | 注意点 |

## 四、面试高频题

**Q: FTP主动模式和被动模式的区别？**

A: 主动模式服务器从端口20主动向客户端发起数据连接；被动模式服务器开放随机端口等待客户端主动连接。被动模式更适合客户端在防火墙/NAT后的场景。

**Q: DHCP的工作原理是什么？为什么是四次交互而不是两次？**

A: DHCP通过Discover->Offer->Request->Ack四次交互完成。需要Request是因为网络中可能有多个DHCP服务器，客户端通过广播Request告知所有服务器选择了哪个Offer，让其他服务器回收分配的地址。

**Q: DHCP租期更新机制？**

A: 客户端在租期的50%时单播向原服务器请求续租，87.5%时广播请求任意服务器续租（重绑定）。如果都失败，租期到期后释放地址重新申请。

**Q: DNS递归查询和迭代查询的区别？**

A: 递归查询由DNS服务器代替客户端向其他服务器查询并返回最终结果；迭代查询DNS服务器只返回下一级服务器地址，由客户端自行继续查询。

**Q: 为什么NTP要分层？Stratum值代表什么？**

A: NTP分层（Stratum）是为了防止环路和保证精度。Stratum 1是主时间服务器（直接连接原子钟/GPS），Stratum值越小精度越高，最大15表示未同步。

## 五、易错点/坑

- **坑1：DHCP接口池和全局池混淆** -- 接口池自动使用接口网段，无需配置network；全局池需要手动配置network并在接口指定dhcp select global
- **坑2：dhcp enable只在系统视图** -- 需要在系统视图和接口视图都使能DHCP相关功能
- **坑3：FTP用户privilege level不够** -- FTP用户级别必须>=3，否则无法登录
- **坑4：Telnet协议未允许** -- 新版VRP默认VTY只支持SSH，需手动protocol inbound telnet
- **坑5：DHCP excluded-ip-address范围写错** -- 别把网关地址或服务器地址排除掉，否则会导致网关不可达
