### 场景1：Python通过telnetlib登录华为设备并创建VLAN

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
"""
华为设备自动化配置脚本 - 使用telnetlib
功能：通过Telnet登录设备并创建VLAN
"""

import telnetlib
import time

# 设备连接信息
HOST = '192.168.10.10'
PASSWORD = 'Huawei@123'

def configure_vlan(host, password, vlan_id, vlan_name):
    """
    通过Telnet登录华为设备创建VLAN
    
    Args:
        host: 设备IP地址
        password: 登录密码
        vlan_id: VLAN编号
        vlan_name: VLAN名称
    """
    try:
        # 建立Telnet连接
        tn = telnetlib.Telnet(host, timeout=10)
        print(f"[*] 正在连接 {host}...")
        
        # 等待密码提示并输入密码
        tn.read_until(b'Password:')
        tn.write(password.encode('ascii') + b'\n')
        
        # 等待登录成功提示符
        result = tn.read_until(b'<Huawei>', timeout=5)
        if b'<Huawei>' in result:
            print('[+] 登录成功')
        else:
            print('[-] 登录失败')
            return
        
        # 进入系统视图
        tn.write(b'system-view\n')
        tn.read_until(b'[Huawei]')
        
        # 创建VLAN
        tn.write(f'vlan {vlan_id}\n'.encode('ascii'))
        tn.read_until(f'[Huawei-vlan{vlan_id}]'.encode('ascii'))
        
        # 配置VLAN名称
        tn.write(f'name {vlan_name}\n'.encode('ascii'))
        tn.read_until(f'[Huawei-vlan{vlan_id}]'.encode('ascii'))
        
        # 返回用户视图保存配置
        tn.write(b'return\n')
        tn.write(b'save\n')
        tn.read_until(b'Are you sure to continue? (y/n)[n]:')
        tn.write(b'y\n')
        
        time.sleep(2)
        result = tn.read_very_eager().decode('ascii')
        
        if 'successfully' in result:
            print(f'[+] VLAN {vlan_id} 创建成功')
        else:
            print(f'[!] 请手动确认配置结果')
        
        # 关闭连接
        tn.close()
        print('[*] 连接已关闭')
        
    except Exception as e:
        print(f'[-] 发生错误: {e}')

if __name__ == '__main__':
    configure_vlan(HOST, PASSWORD, vlan_id=10, vlan_name='Automation_Test')
```

### 场景2：批量备份多台设备配置 [补充]

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
"""
批量备份华为设备配置
"""

import telnetlib
import time
from datetime import datetime

# 设备清单
DEVICES = [
    {'ip': '192.168.1.1', 'password': 'Huawei@123'},
    {'ip': '192.168.1.2', 'password': 'Huawei@123'},
    {'ip': '192.168.1.3', 'password': 'Huawei@123'},
]

def backup_config(device_info):
    """备份单台设备配置"""
    ip = device_info['ip']
    password = device_info['password']
    
    try:
        tn = telnetlib.Telnet(ip, timeout=10)
        tn.read_until(b'Password:')
        tn.write(password.encode('ascii') + b'\n')
        tn.read_until(b'<Huawei>')
        
        # 设置屏幕长度防止分页
        tn.write(b'screen-length 0 temporary\n')
        tn.read_until(b'<Huawei>')
        
        # 查看当前配置
        tn.write(b'display current-configuration\n')
        config = tn.read_until(b'<Huawei>', timeout=10).decode('ascii')
        
        # 保存到文件
        filename = f'backup_{ip}_{datetime.now().strftime("%Y%m%d_%H%M%S")}.txt'
        with open(filename, 'w', encoding='utf-8') as f:
            f.write(config)
        
        tn.close()
        print(f'[+] {ip} 配置备份完成 -> {filename}')
        return True
        
    except Exception as e:
        print(f'[-] {ip} 备份失败: {e}')
        return False

def main():
    print('='*50)
    print('华为设备配置批量备份工具')
    print(f'开始时间: {datetime.now()}')
    print('='*50)
    
    success = 0
    for device in DEVICES:
        if backup_config(device):
            success += 1
        time.sleep(1)
    
    print(f'\n[*] 备份完成: {success}/{len(DEVICES)} 台设备成功')

if __name__ == '__main__':
    main()
```

## 四、面试高频题

**Q: 为什么网络工程师需要学Python？**

A: 网络规模扩大后，手动配置数千台设备效率低、易出错。Python可以实现批量配置下发、状态采集、配置备份、故障排查等自动化操作，大幅提升运维效率。

**Q: Python的telnetlib和paramiko有什么区别？**

A: telnetlib基于Telnet协议，明文传输，不安全，适合实验环境。paramiko基于SSH协议，加密传输，安全性高，是生产环境的推荐选择。

**Q: 解释型语言和编译型语言的区别？各有什么优缺点？**

A: 编译型语言执行前编译成机器码，运行速度快但不能跨平台。解释型语言运行时逐行翻译，可移植性好但速度较慢。Python是解释型语言，开发效率高。

**Q: 网络自动化除了Python还有哪些工具？**

A: Ansible（无代理自动化工具，使用YAML）、Netmiko（多厂商SSH连接库）、NAPALM（网络自动化抽象层）、SaltStack、Puppet、Chef等。

**Q: Python自动化脚本连接华为设备时，为什么要处理分页？**

A: 华为设备默认显示分页（--More--），脚本无法交互按键会导致输出被截断。通过screen-length 0 temporary命令关闭分页，确保一次性获取完整输出。

## 五、易错点/坑

- **坑1：编码问题** -- telnetlib需要bytes类型数据，字符串要用encode('ascii')转换，接收后要用decode()解码
- **坑2：未处理分页** -- 华为设备默认分页显示，脚本里必须先screen-length 0 temporary关闭分页
- **坑3：时序问题** -- read_until和write之间需要时间缓冲，复杂场景建议用time.sleep()或read_very_eager()
- **坑4：提示符匹配失败** -- 华为不同视图的提示符不同（<Huawei> / [Huawei] / [Huawei-xxx]），read_until的匹配字符串要写对
- **坑5：生产环境用Telnet** -- Telnet明文传输不安全，生产环境务必使用SSH（paramiko/Netmiko）
