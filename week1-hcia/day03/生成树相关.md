# HCIA - 生成树协议（STP/RSTP/MSTP）

## 一、核心概念速记
| 概念 | 一句话定义 |
|------|-----------|-------------|
| STP | 通过阻塞冗余端口消除二层环路，同时保留备份链路 | "STP在交换网络中选举根桥，通过比较BID、RPC、Port ID决定阻塞哪个端口，把环形拓扑修剪成无环树形。" |
| BID/根桥 | 桥ID=优先级+MAC，BID最小的交换机成为根桥 | "桥优先级默认32768，步长4096，越小越优先；优先级相同再比MAC地址。" |
| RPC/根路径开销 | 接口到根桥的Cost累加值（入方向） | "根端口选举看RPC，注意是沿途所有入接口Cost累加，不是出方向。" |
| 根/指定/阻塞端口 | 根端口离根最近；指定端口每段链路一个；其余阻塞 | "非根桥只有一个根端口；每段链路一个指定端口；既不是根也不是指定的就被阻塞。" |
| RSTP | STP的快速收敛版本，收敛时间从50s降到秒级 | "RSTP引入Alternate/Backup端口、边缘端口和P/A协商机制，实现快速收敛。" |
| MSTP | 多生成树协议，不同VLAN映射到不同生成树实例 | "STP/RSTP所有VLAN共享一棵树，阻塞链路浪费带宽；MSTP让不同VLAN走不同树，实现负载均衡。" |

## 二、华为命令配置模板（直接复制粘贴）
### 场景1：STP基础配置（指定根桥+阻塞指定端口）
```bash
# SW1作为根桥
[SW1] stp mode stp
[SW1] stp root primary           # 优先级自动设为0
[SW1] stp enable

# SW2作为备份根桥
[SW2] stp mode stp
[SW2] stp root secondary        # 优先级自动设为4096
[SW2] stp enable

# SW3普通交换机
[SW3] stp mode stp
[SW3] stp priority 32768
[SW3] stp enable

# 验证
[SW3] display stp brief          # 查看端口角色与状态
[SW3] display stp topology-change  # [补充] 查看拓扑变化情况

###场景2：修改路径开销控制阻塞端口位置
# 统一Cost计算方法（全网必须一致）
[SW1] stp pathcost-standard dot1d-1998

# 修改接口Cost，影响根端口/指定端口选举
[SW3-GigabitEthernet0/0/22] stp cost 20000

# 修改接口优先级，影响指定端口选举
[SW3-GigabitEthernet0/0/22] stp priority 128

###场景3：RSTP边缘端口配置（接终端立即转发）[补充]
[SW3-GigabitEthernet0/0/1] stp edged-port enable
[SW3-GigabitEthernet0/0/1] stp bpdu-filter enable   # [补充] 可选，过滤终端口BPDU

##四、面试高频题
Q: STP解决什么问题？不解决会有什么后果？
A: 解决二层环路导致的广播风暴和MAC地址表漂移。不解决会造成网络瘫痪、设备CPU耗尽。
Q: STP选举根桥、根端口、指定端口的顺序和依据？
A: ①根桥：BID最小（先比优先级，再比MAC）；②根端口：RPC最小→对端BID最小→对端Port ID最小；③指定端口：RPC最小→本端BID最小→本端Port ID最小。
Q: STP端口状态迁移时间和收敛时间？
A: Listening 15s + Learning 15s = 30s才能Forwarding。根桥故障约50s（20s Max Age + 30s），直连故障30s。
Q: RSTP为什么比STP快？
A: 新增Alternate端口（根端口备份）和Backup端口（指定端口备份），端口失效立即切换；边缘端口直接Forwarding；引入P/A机制主动协商，不依赖定时器。
Q: 边缘端口有什么风险？
A: 边缘端口如果误接了交换机并收到BPDU，会立即失去边缘属性参与STP计算，若对端也是边缘端口可能形成环路。建议配合BPDU保护。
Q: 为什么现网用MSTP而不是RSTP？
A: RSTP所有VLAN共享一棵生成树，阻塞链路不承载任何流量，造成带宽浪费。MSTP将VLAN映射到不同实例，不同实例阻塞不同端口，实现负载均衡。

##五、易错点/坑
• RPC是入方向Cost累加：从根桥到本机沿途所有入接口Cost之和，不是出方向，也不是单向某一段
• STP默认优先级32768，步长4096：可配置值为0/4096/8192...，不是任意整数
• 华为交换机默认运行MSTP：不是STP，实验考试需手动stp mode stp或rstp
• Cost计算方法需全网一致：dot1d-1998/dot1t/legacy三种标准，混用会导致选路错误
• 根桥建议手动指定：不要让交换机自动选举，否则性能差的交换机可能因MAC小成为根桥
• 拓扑变化导致MAC地址表老化缩短为15秒：收到TCN后，交换机将MAC老化时间改为Forward Delay（默认15s），可能导致短暂泛洪
• 修改STP优先级不立即重新选举：需等待BPDU老化，可stp root primary强制切换
• RSTP的P/A机制要求点对点链路：共享介质（Hub环境）或半双工链路P/A可能失败，退回到STP方式收敛
