## 实验一：网络配置备份目录流水线（Ch6 基础 + Ch5 权限复习）

| 命令 | 作用 | 常用场景 |
|------|------|----------|
| `cat &gt; 文件 &lt;&lt; 'EOF'` | 多行内容写入文件 | 快速写配置模板、脚本骨架 |
| `head -n 5 文件` | 看前 5 行 | 日志太大，只看开头 |
| `tail -n 5 文件` | 看后 5 行 | 看日志最新报错 |
| `nl 文件` | 带行号显示 | 排查"第 XX 行出错" |
| `file 文件` | 判断文件类型 | 拿到未知文件先看类型 |
| `chmod 644 文件` | 设为只读（rw-r--r--） | 防止重要配置文件被误改 |
| `cp 源 目标` | 复制文件 | 备份配置文件：`cp sshd.cfg sshd.cfg.bak` |
| `mv 原 新` | 移动或重命名 | 配置文件版本管理：`mv v1.txt v2.txt` |

## 实验二：日志排查实战（Ch6 过滤 + Ch4 重定向复习）

| 命令 | 作用 | 常用场景 |
|------|------|----------|
| `cat 文件 \| head -5` | 管道组合：先输出再取前 5 行 | 快速预览大文件 |
| `grep "ERROR" 文件` | 筛出包含 ERROR 的行 | 从日志里找报错、找 IP |
| `grep "192.168.1.1[0-5]" 文件` | 正则筛选 IP 段 | 模糊匹配日志来源 |
| `less 文件` | 分页查看，可搜索 | 大日志文件浏览 |
| `/关键词` + `n` + `q` | less 内搜索 + 下一个 + 退出 | 在 less 里定位 ERROR |
| `for ... &gt;&gt; 文件` | 循环追加写入 | 批量生成测试日志数据 |

## 实验三：文件搜索全家桶（which / locate / find）

| 命令 | 作用 | 常用场景 |
|------|------|----------|
| `which 命令` | 查命令在 `$PATH` 里的位置 | 确认用的是哪个版本的命令 |
| `whereis 命令` | 查命令 + 手册 + 源码位置 | 比 which 更全面 |
| `locate 文件名` | 快速模糊搜文件名 | 记得文件名但不知道在哪 |
| `updatedb` | 更新 locate 的数据库 | locate 找不到新文件时更新 |
| `find /etc -name "*.conf" -type f 2&gt;/dev/null` | 实时遍历按名搜索 | 找散落在各处的配置文件 |
| `find /var/log -type f -size +10M` | 按大小找文件 | 磁盘满了，找大日志元凶 |
| `find /var/log -type f -mtime +30` | 按修改时间找 | 清理旧日志、判断能否删除 |
| `find /usr/bin -type f -perm /4000` | 找带 SUID 的文件 | 安全审计，排查提权风险 |
| `2&gt;/dev/null` | 把错误信息丢进黑洞 | 避免满屏 Permission denied |

## 实验四：特殊权限与粘滞位（SUID / SGID / Sticky）

| 命令 | 作用 | 常用场景 |
|------|------|----------|
| `chmod 1777 目录` | 粘滞位（Sticky）：人人可写，只删自己的 | 共享上传目录、模拟 `/tmp` |
| `chmod 4755 文件` | SUID：执行时临时获得 owner 权限 | 类似 `passwd` 命令的机制 |
| `chmod 2775 目录` | SGID：目录内新建文件自动继承属组 | 项目组共享目录 |
| `chmod 7777 目录` | SUID + SGID + Sticky 全开 | 特殊场景（极少用，了解即可） |
| `find / -perm /4000` | 找带 SUID 的文件 | 安全审计 |
| `find / -perm /2000` | 找带 SGID 的文件 | 排查异常组权限 |
| `ls -ld /tmp` | 查看系统真实 `/tmp` 权限 | 理解为什么系统目录是 `t` 结尾 |
| `ls -li` | 查看文件 inode 号 | 验证硬链接是否指向同一个 inode |

## 特殊权限速查口诀

| 权限 | 数字 | 符号 | 口诀 |
|------|------|------|------|
| **SUID** | 4 | `s`（owner 位） | 借主人的钥匙，开一次门 |
| **SGID** | 2 | `s`（group 位） | 入乡随俗，户口跟目录走 |
| **Sticky** | 1 | `t`（other 位） | 垃圾桶规则，只能扔自己的 |
