## 实验一：磁盘容量侦查兵（df / du + Ch6 find 温习）

| 命令 | 作用 | 常用场景 |
|------|------|----------|
| `df -h` | 查看磁盘分区使用率（人类可读） | 磁盘满了先敲这个 |
| `df -h /home` | 看指定挂载点使用率 | 定位哪个分区快满了 |
| `du -sh /etc` | 看目录总大小 | 定位哪个目录占空间 |
| `du -sm /var/* \| sort -nr \| head -5` | 找出最大的 5 个子目录 | 磁盘满了快速定位元凶 |
| `find /var/log -type f -size +10M` | 找大于 10M 的文件 | 温习 Ch6，配合 du 使用 |

## 实验二：虚拟磁盘全流程（fdisk / mkfs / mount / umount）

| 命令 | 作用 | 常用场景 |
|------|------|----------|
| `dd if=/dev/zero of=disk.img bs=1M count=100` | 创建指定大小的空文件 | 生成虚拟磁盘、测试文件 |
| `losetup --find --show disk.img` | 挂载为 loop 设备 | 虚拟磁盘实验专用 |
| `fdisk /dev/loop0` | 交互式分区（n/p/1/回车/回车/w） | 给新硬盘分区 |
| `partprobe /dev/loop0` | 通知内核刷新分区表 | fdisk 后常见踩坑点，必须执行 |
| `mkfs.xfs /dev/loop0p1` | 格式化为 xfs 文件系统 | 分区后必须格式化才能存数据 |
| `mount /dev/loop0p1 /mnt` | 挂载设备到目录 | 让分区能存取文件 |
| `umount /mnt` | 卸载设备 | 维护磁盘前必须先卸载 |
| `losetup -d /dev/loop0` | 删除 loop 设备 | 实验结束清理资源 |

## 实验三：硬链接与软链接（ln + Ch6 inode 温习）

| 命令 | 作用 | 常用场景 |
|------|------|----------|
| `ln 原文件 硬链接` | 硬链接：与原文件共享 inode | 重要文件多路径保护，防误删 |
| `ln -s 原文件 软链接` | 软链接：快捷方式，独立 inode | 配置文件跨目录引用 |
| `ls -li` | 查看 inode 号 | 验证硬链接是否指向同一个 inode |
| `rm 原文件` | 删除原文件 | 验证：硬链接仍可访问，软链接失效 |
| `readlink 软链接` | 查看软链接指向的真实路径 | 排查软链接是否指向错误位置 |

## 实验四：Swap 空间与开机挂载（swapon / free / fstab）

| 命令 | 作用 | 常用场景 |
|------|------|----------|
| `free -m` | 查看内存和 swap（MB 为单位） | 排查系统卡顿、内存不足 |
| `swapon -s` | 查看当前 swap 使用情况 | 确认有几个 swap 在生效 |
| `dd if=/dev/zero of=swapfile bs=1M count=128` | 创建 swap 文件 | 内存吃紧时临时应急 |
| `chmod 600 swapfile` | 设置严格权限（rw-------） | swap 文件必须权限严格，防泄露 |
| `mkswap swapfile` | 格式化为 swap 格式 | 创建后必须格式化 |
| `swapon swapfile` | 启用 swap | 内存不足时临时扩容 |
| `swapoff swapfile` | 关闭 swap | 实验结束或维护时关闭 |
| `cat /etc/fstab` | 查看开机挂载表 | 理解六列：设备名、挂载点、文件系统、参数、dump、fsck 顺序 |

## 链接类型对比

| 特性 | 硬链接（Hard Link） | 软链接（Symbolic Link） |
|------|---------------------|------------------------|
| inode | 与原文件相同 | 独立 inode |
| 跨文件系统 | ❌ 不可以 | ✅ 可以 |
| 跨目录 | ✅ 可以 | ✅ 可以 |
| 原文件删除后 | ✅ 仍可访问 | ❌ 失效（ dangling ） |
| 目录 | ❌ 不能硬链接目录 | ✅ 可以软链接目录 |
| 用途 | 备份保护 | 快捷引用、版本切换 |

## 磁盘管理速查流程
磁盘满了？
├── df -h          → 看哪个分区满了
├── du -sh /*      → 看哪个目录最大
├── find / -size +100M → 找大文件
└── 确认能删后 → rm / 压缩归档
新硬盘上线？
├── fdisk 分区     → partprobe 刷新
├── mkfs.xfs 格式化
├── mount 挂载
└── /etc/fstab 配置开机自动挂载
