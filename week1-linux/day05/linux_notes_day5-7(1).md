## Ch5 文件权限与属性管理

### 1. `ls -la` 输出解析

使用 `ls -la` 查看文件详情时，每行输出格式如下：

```
-rwxr-xr-- 1 root root 1234 Jan 1 12:00 filename
```

| 字段位置 | 含义 |
|---------|------|
| 第 1 位 | 文件类型 |
| 第 2-4 位 | 文件拥有者权限 |
| 第 5-7 位 | 所属群组权限 |
| 第 8-10 位 | 其他用户权限 |

#### 文件类型标识

| 符号 | 含义 |
|-----|------|
| `d` | 目录 |
| `-` | 普通文件 |
| `l` | 链接文件 |
| `b` | 可供存储的周边设备 |
| `c` | 设备文件中的串行端口设备 |

#### 权限字符含义

| 字符 | 权限 | 数字表示 |
|-----|------|---------|
| `r` | 可读 | 4 |
| `w` | 可写 | 2 |
| `x` | 可执行 | 1 |

> 三组权限分别对应：**文件拥有者** / **群组用户** / **其他用户**

---

### 2. 修改文件所属组群：`chgrp`

| 选项 | 说明 |
|-----|------|
| `-R` | 递归修改，连同子目录下所有文件 |

```bash
# 基本语法
chgrp [-R] 组群名 文件或目录

# 示例：将文件所属组改为 users
chgrp users initial-setup-ks.cfg

# 递归修改
chgrp -R dirname/filename
```

---

### 3. 修改文件所有者：`chown`

```bash
# 基本语法
chown [-R] 账号名称 文件或目录

# 同时修改所有者与组群
chown [-R] 账号名称:群组名称 文件或目录

# 示例：将文件所有者改为 bin
chown bin initial-setup-ks.cfg

# 示例：同时改为 bin:bin
chown -R bin:bin .bashrc_test
```

---

### 4. 修改文件权限：`chmod`

#### 数字模式

```bash
# 语法：chmod [-R] xyz 文件或目录
# x=所有者, y=群组, z=其他用户

chmod 777 .bashrc    # rwxrwxrwx
chmod 755 file       # rwxr-xr-x
chmod 644 file       # rw-r--r--
```

#### 符号模式

```bash
# 直接设置权限
chmod u=rwx,g=rwx,o=rwx 文件或目录

# 添加/移除权限
chmod a+w 文件或目录    # 所有用户添加写权限
chmod a-x 文件或目录    # 所有用户移除执行权限
```

---

### 5. 应用示例

```bash
# 复制文件
cp .bashrc .bashrc_test

# 同时修改所有者和组群
chown -R bin:bin .bashrc_test
```

## Ch6 文件与目录管理

### 1. 路径概念

| 类型 | 说明 | 示例 |
|-----|------|------|
| **绝对路径** | 从根目录 `/` 写起 | `/usr/share/doc` |
| **相对路径** | 不从 `/` 写起，相对当前目录 | `cd ../man` |

#### 特殊目录符号

| 符号 | 含义 |
|-----|------|
| `.` | 当前目录 |
| `..` | 上一层目录 |
| `-` | 前一个工作目录 |
| `~` | 当前用户的主文件夹 |
| `~x` | 用户 x 的主文件夹 |

---

### 2. 常用目录操作指令

| 指令 | 全称 | 功能 |
|-----|------|------|
| `cd` | Change Directory | 切换目录 |
| `pwd` | Print Working Directory | 显示当前目录 |
| `mkdir` | Make Directory | 创建新目录 |
| `rmdir` | Remove Directory | 删除空目录 |
| `mv` | Move | 移动/重命名文件或目录 |

```bash
# mv 语法示例
mv /bin/ls /root           # 移动文件
mv mvtest mvtest2          # 目录重命名
mv bashrc bashrc1 bashrc2 mvtest2   # 多文件移动
```

---

### 3. `$PATH` 环境变量

存储可执行文件的搜寻路径，系统会依序在 `$PATH` 中的目录查找指令。

---

### 4. `ls` 指令常用选项

| 选项 | 说明 |
|-----|------|
| `-a` | 显示全部文件（含隐藏文件） |
| `-A` | 显示全部文件（不含 `.` 和 `..`） |
| `-d` | 仅列出目录本身，不列出目录内容 |
| `-f` | 直接列出结果，不进行排序 |
| `-F` | 附加文件类型标识（`*`可执行 `/`目录 `=`socket `\|`FIFO） |
| `-h` | 文件大小以 KB、MB 等人类可读格式显示 |
| `-i` | 列出 inode 号码 |
| `-l` | 长格式输出，包含属性与权限 |
| `-n` | 列出 UID 与 GID（非名称） |
| `-R` | 递归列出子目录内容 |
| `-r` | 反向排序 |
| `-s` | 按文件大小排序 |
| `-t` | 按时间排序 |
| `--color=never` | 不显示颜色 |
| `--color=always` | 显示颜色 |
| `--full-time` | 完整时间模式（年/月/日/时/分） |
| `--time={atime,ctime}` | 显示访问时间或权限变更时间 |

### 5. 复制、删除与移动

#### `cp` 复制文件

```bash
# 语法
cp [-adfilprsu] 来源文件(source) 目标文件(destination)

# 常用选项
# -a : 递归复制，保留所有属性（相当于 -dR --preserve=all）
# -i : 覆盖前询问确认
# -r : 递归复制目录
```

> **复制前需确认：**
> 1. 是否完整保留来源文件信息？
> 2. 来源文件是否为链接文件？
> 3. 来源文件是否为特殊文件（FIFO / Socket）？
> 4. 来源文件是否为目录？

#### `rm` 移除文件或目录

```bash
rm [-fir] 文件或目录
```

#### 操作示例

```bash
# 复制文件到 /tmp
cp ~/.bashrc bashrc
cp ~/.bashrc bashrc1
cp ~/.bashrc bashrc2

# 创建目录并更名
mkdir mvtest
mv mvtest mvtest2

# 多文件移动
mv bashrc bashrc1 bashrc2 mvtest2
```

### 7. 文件时间属性与 `touch`

#### 三种时间类型

| 时间类型 | 说明 | 触发条件 |
|---------|------|---------|
| **mtime** (modification time) | 内容修改时间 | 文件内容数据变更时更新 |
| **ctime** (status time) | 状态变更时间 | 文件权限/属性变更时更新 |
| **atime** (access time) | 访问时间 | 文件内容被读取时更新 |

> `ls -l` 默认显示的是 **mtime**

```bash
# 同时查看三种时间
date; ls -l /etc/文件名; ls -l --time=atime /文件名
```

#### `touch` 指令

```bash
# 功能：
# 1. 创建空文件
# 2. 修改文件时间为当前时间

touch 文件名
```

## Ch8 压缩、解压缩与打包

### 1. 常见压缩格式

| 格式 | 工具 | 特点 | 查看压缩文件内容 |
|-----|------|------|-----------------|
| `.gz` | `gzip` | 最常用，压缩速度快 | `zcat` / `zmore` / `zless` |
| `.bz2` | `bzip2` | 压缩比更高 | `bzcat` / `bzmore` / `bzless` |
| `.xz` | `xz` | 压缩比最高 | `xzcat` / `xzmore` / `xzless` |

> 复习：`cat` = 全部显示 / `more` = 可向下翻页 / `less` = 可上下翻页

#### 解压缩

```bash
gzip -d 文件名     # 解压 .gz
bzip2 -d 文件名    # 解压 .bz2
xz -d 文件名       # 解压 .xz
```

---

### 2. `tar` 打包指令

```bash
# 打包 + 压缩
 tar -jcv -f filename.tar.bz2 要打包的文件或目录

# 查询 tar 包内容
 tar -jtv -f filename.tar.bz2

# 解压缩
 tar -jxv -f filename.tar.bz2

# 解压包内单个文件
 tar -jxv -f filename.tar.bz2 包内文件名
```

| 选项 | 含义 |
|-----|------|
| `-j` | 使用 bzip2 压缩/解压 |
| `-z` | 使用 gzip 压缩/解压 |
| `-J` | 使用 xz 压缩/解压 |
| `-c` | 创建新打包文件 (create) |
| `-x` | 解打包/解压缩 (extract) |
| `-t` | 查看打包内容 (list) |
| `-v` | 显示过程信息 (verbose) |
| `-f` | 指定文件名 (filename) |
| `-C` | 指定解压到特定目录 |

#### `tarfile` vs `tarball`

| 术语 | 说明 |
|-----|------|
| **tarfile** | 仅打包（未压缩） |
| **tarball** | 打包 + 压缩 |

## Ch9 vi/vim 文本编辑器

### 三种操作模式

```
+-----------+      i,a,o      +-----------+      Esc      +-----------+
| 一般指令  | --------------> | 编辑模式  | ------------> | 命令行模式 |
| (Normal)  | <-------------- | (Insert)  | <------------ | (Command)  |
+-----------+      Esc        +-----------+     : / ?      +-----------+
```

### 基本操作流程

```bash
# 1. 打开或创建文件
vi /bin/vi 欲创建的文件名

# 2. 按 i 进入编辑模式，开始编辑

# 3. 按 Esc 回到一般指令模式，输入 :wq 存盘退出
#    :w  保存
#    :q  退出
#    :q! 强制退出不保存
#    :wq 保存并退出

# 4. 用 ls -l 查看创建的文件
ls -l 文件名
```

### 模式说明

| 模式 | 说明 |
|-----|------|
| **一般指令模式** | 打开文件的默认模式，可移动光标、删除、复制、粘贴 |
| **编辑模式** | 按 `i`、`a`、`o` 等进入，可自由编辑文本内容 |
| **命令行模式** | 按 `:` `/` `?` 进入，可执行保存、退出、搜寻替换等命令 |

## Ch11 正则表达式与文件格式化处理

### 1. 撷取命令

| 指令 | 功能说明 |
|-----|---------|
| `cut` | 在整齐格式中提取指定字段/字符段 |
| `grep` | 分析每一行，提取包含目标信息的行 |

> `\|` 为管道符（`pipe`），用于连接多个指令


- `cat`、`more`、`less`、`head`、`tail` 用于文件内容查阅
